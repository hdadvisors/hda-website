Roboto Slab — variable-axis specimen

One variable file covers the entire weight axis. Any integer 100–900 is valid, so headings can dial in a tone rather than snap to named weights. Use font-variation-settings: "wght" N or simply font-weight: N.

Lato — self-hosted weight inventory

All ten cuts shipped in /fonts. Use 400 for body, 700 for emphasis & UI labels, 900 for display accents. 100/300 are available but should be reserved for large sizes — they lose legibility below 18px.
